# Create your project’s world

Publish a profile, explore Atlas and attach research.

[Live guide](https://parallaxlaunch.live/docs/creators) · [Guide index](README.md)

Creator Studio lets a project publish a recognizable home in the PARALLAX universe.

## Publish a world

1. Open [Creator Studio](https://parallaxlaunch.live/studio) and sign in.
1. Verify the creator wallet when prompted, then enter the project’s identity, description and links.
1. Review the design and any token contract you attach before publishing.
1. Return to [My workspace](https://parallaxlaunch.live/creator) to manage supported updates.

Project access follows the authorized account and original creator wallet. A SolHandle is an identity label, not a replacement for project permission.

## Atlas and community listings

[Project Atlas](https://parallaxlaunch.live/planets) is a way to discover worlds and community-submitted profiles. A listing or verified handle does not independently establish token affiliation or endorse a project. Curated editorial worlds are identified separately.

## Premium Worlds

Optional Premium Worlds purchases provide supported presentation upgrades for a particular project. Review the current checkout, recipient and amount before signing. Premium is separate from Gold holder access and does not change research conclusions.

## Attach a research panel

Collect a Passport for the exact linked token, preview it in [Utility](https://parallaxlaunch.live/utility), and use the explicit publication controls if your project is eligible. Publishing a panel makes the selected research available publicly. Removing a panel does not necessarily revoke an already shared Passport link; manage sharing in Project Passports.
