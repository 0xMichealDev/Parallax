# Development roadmap

Status recorded October 20, 2026. This page separates available code from integration checks and future product work. It does not promise delivery dates.

## Available in this repository

- SolHandle forward and verified Primary Handle resolution.
- Address fallback and bounded account-read transport.
- Browser identity expiry, refresh, request deduplication and stale-response rejection.
- Offline tests, source provenance, integration documentation and contribution templates.

## Available in the hosted platform

Project Passports, Wallet Watch, Project Atlas and creator tools, Gold holder access, Gold Assistant and SolHandle identity display. Read the [product documentation](https://parallaxlaunch.live/docs) for eligibility, limits and source availability. These platform features are not all implemented in this repository.
