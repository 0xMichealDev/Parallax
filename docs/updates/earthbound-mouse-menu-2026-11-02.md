# Earthbound mouse controls and menu entry

Right mouse holds aim; left mouse fires. Releasing right mouse exits aim. Mouse movement controls the view after clicking into mouse-look; Escape releases the pointer. Introduction and equipment help match these controls. Controller LT/RT bindings remain unchanged.

Play Earthbound is a primary sidebar item and a first-group link in the shared desktop/mobile menu, taking players directly to /explore#walk-on-earth.

Automated input and navigation checks and production build validate this release. Physical mouse/controller visual testing is not claimed.
