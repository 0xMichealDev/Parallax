Handle ownership

The official SolHandle SDK checks the registry, official collection and current asset owner on-chain.

Wallet verification

A signed message proves control of a wallet for a Parallax account. Resolving an @handle never signs in or verifies a wallet for you.

Project permissions

Editing requires the original creator account and a current signature from the project’s recorded wallet. A handle transfer changes neither requirement.

When a handle changes hands

New lookups resolve the current owner. A stale primary record is not shown for the former owner. Identity labels expire within one minute and can be rechecked. Returning to a backgrounded page triggers a fresh identity check; the recorded wallet addresses stay visible while ownership is checked again. Existing watchlists, project records, wallet proofs, and Pro access never move with a handle.
