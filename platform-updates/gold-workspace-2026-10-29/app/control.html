in view.

SHA-256 · File integrity
↓

ORIGINAL PASSPORT EXPORT

The file is hashed in your browser. Only its report ID is sent to retrieve your saved fingerprint. File integrity can be checked without signing in. Matching the saved original requires the account that created the report.

What a match means

The exported source payload matches the snapshot saved by PARALLAX. This does not establish that the source data is true, that a token is safe, or that the report is recorded on a blockchain. AI summaries are separate from the fingerprinted payload.

About Project Passports

OCTOBER 13, 2026 / RELEASE 03

Research you can return to.

Available: on-demand Solana token passports, linked sources, account-saved reports, AI research summaries with source references, passport comparisons and AI change explanations, wallet watchlists and snapshots, JSON exports, fingerprint comparisons, previous-scan change summaries, and optional revocable report links.

Prepared for connection: Private Telegram pairing, owner-managed community channel alerts, per-wallet native SOL transfer rules, and delivery history. Bot and monitoring service activation are required. On-chain report fingerprints remain planned.

Research tools provide information, not investment recommendations. Price and liquidity can change after a snapshot. Missing data is shown as unavailable.
