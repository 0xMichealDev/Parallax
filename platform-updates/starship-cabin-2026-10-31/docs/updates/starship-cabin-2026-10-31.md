# Starship flight deck and Windows graphics compatibility

The flight deck now has fitted padded seats with harnesses and support rails, separate recessed instrument screens, warm perimeter and overhead lighting, framed windows, storage lockers, ventilation slots and a rear pressure hatch. The center aisle and existing flight controls remain usable. A Starship flight deck option in the walking travel menu provides direct access. Instruments are illustrative fictional expedition readouts, not real telemetry or a reproduction of an actual SpaceX interior.

Edge's GPU diagnostic log reported an ambiguous integer vector-constructor overload during deferred D3D pixel-shader compilation, followed by context loss and a GPU-process crash. Earthbound and planet shaders now use explicit floating-point vector components. A regression check prevents integer literal vector components from returning. Edge also recovered on the previous live release before this change, so that recovery alone is not evidence that the patch fixed every graphics failure.

Local Edge inspection reached Earthbound's walking state with the compatibility patch. Cabin geometry, movement boundaries, entry recovery and flight handoff are covered by focused tests. Visual inspection of the redesigned cabin remains limited: automatic approval review blocked native window screenshots because browser controls/bookmarks would be included; the in-app browser still reports disabled graphics. This release does not change browser settings or guarantee recovery of a browser that has disabled WebGL.

No new Meshy generation or credits were used. Existing textured assets are retained.
