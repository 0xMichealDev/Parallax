# Discovery Missions / first expedition

`/discover` introduces three free, account-saved missions: save a Project Passport (25 XP / First Signal), open a comparison of two snapshots for the same token collected at different times (50 XP / Evidence Explorer), and follow a planet or save a research project (25 XP / In Orbit). All three earn the Pathfinder designation and 100 XP total. They can be completed in any order. XP is a non-transferable completion counter with no monetary, token, premium or airdrop entitlement. No rewards are paid.

The main dashboard has a Continue your mission card. Research and Saved projects have compact progress cards; the dedicated page contains the private Explorer profile, recognition dates and next steps. Existing realistic planet artwork supplies the visual identity. No new background polling, wallet connection, AI call or scan is introduced.

Migration 0013 adds `discovery_achievements`, unique by account and mission. Points are derived from a fixed server catalogue. There is no endpoint accepting a completed flag or points amount. Same-origin authenticated POST `/api/discovery/sync` recognizes existing account-owned saved Passport and follow evidence and prior recorded Saved projects review days. GET `/api/discovery/progress` only reads. Report/follow removal leaves already-earned achievements intact; the achievements contain no wallet, token, project or report identifier.

`/api/discovery/compare` accepts two report IDs, loads both under the current account, validates the Passport schema and sources, and runs the same comparison validation used by the research tools. Identical IDs, equal collection times, different tokens/networks, missing reports, and another account’s reports cannot earn an achievement. The research UI calls this only when a comparison is displayed, including the previous-snapshot shortcut. Automatic previous-snapshot lookups do not count. Successful research/follow actions refresh progress. A failed progress write does not undo or block the research; comparisons retain their IDs in page memory for a retry. No draft or private progress is kept in browser storage. Page-hide clears private UI and back/forward restoration reloads it.

Existing work is recognized on profile synchronization. A prior comparison without a recorded Saved projects review needs to be reopened. Dates are recognition dates, not invented historical completion dates. Deleting evidence before it was recognized cannot be reconstructed. These badges indicate tool use, not expertise, endorsement, or token safety.

Verification: SQLite integration tests in `tests/discovery.mjs`; real client-script fixtures in `tests/discovery-client.mjs`; existing following, creator feed, research and traffic regression tests; TypeScript, HTML/assets and production build. Browser/iPhone visual checks are unavailable in the managed environment.
