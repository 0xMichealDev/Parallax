# Security reports

For a suspected vulnerability, ask a PARALLAX administrator in the [community](https://t.me/Parallaxcommunity) for a private reporting channel before disclosing details. Do not post exploits, seed phrases, signatures or API credentials publicly. No response-time or bounty commitment is made by this preview.

Provide the affected version, a minimal reproduction and the likely impact using test data. Handle ownership is not project authorization. The included checks are automated fixtures, not an independent security audit.
